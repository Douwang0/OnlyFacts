Au lancement du site :

Si l'utilisateur a déjà un compte :
 - Se connecter en rentrant son nom, son prenom, et son mot de passe
 - Cliquer sur le bouton de connexion (login), vous êtes redirigé sur la page principale.

Si l'utilisateur n'a pas de compte :
 - cliquer sur "s'inscrire"
 - créer un prenom, nom, et mot de passe, vous êtes redirigé sur le login.
 - Faire les mêmes instructions pour un utilisateur ayant un compte.


Sur la page principale :
 - Ecrire le message souhaité dans le bloc à cet effet, cliquer sur "envoyer pour publier
 - "upvote" les postes que vous aimez en cliquant sur le bouton upvote
 - Cliquer sur la page profil pour voir votre profil
 - Cliquer sur la login pour vous connecter a un autre compte.
