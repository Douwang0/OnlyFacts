# 🧠 OnlyFacts

> A simple web application to share and interact with posts.

## 📌 Description

**OnlyFacts** est une application web développée avec Flask permettant aux utilisateurs de :

- créer un compte
- publier des messages
- consulter les posts des autres
- interagir via un système de votes

Le projet est réalisé dans le cadre d’un travail d’équipe (M.I.G.A).

## 🚀 Features

### 👤 User Management
- Inscription (nom, prénom, mot de passe)
- Connexion / Déconnexion
- Gestion de session utilisateur

### 📝 Posts
- Création de posts
- Affichage de tous les posts
- Informations affichées :
  - Auteur
  - Date
  - Nombre de votes

### 👍 Voting System
- Possibilité de voter pour un post
- Protection contre les votes multiples

### 🔎 Sorting & Display
- Tri des posts par :
  - Date
  - Nombre de votes
- Ordre :
  - Croissant
  - Décroissant

### 🖥️ Interface
- Page d’accueil (feed de posts)
- Page de connexion
- Page d’inscription
- Page de profil
- Navigation simple entre les pages
